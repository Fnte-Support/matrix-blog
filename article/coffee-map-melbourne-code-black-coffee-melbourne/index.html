      墨爾本｜Code Black Coffee, Melbourne — 咖啡地圖

      咖啡地圖 2026-06-30 By Daily Coffee

      Code Black Coffee, Melbourne

      Code Black Coffee 是墨爾本精品咖啡圈的代表品牌，由 Mark Dundon 等資深咖啡人共同創立，2009 年成立至今已成為澳洲第三波咖啡的重要推手之一。自有烘焙廠位於 Brunswick，所有咖啡豆皆在墨爾本當地烘焙完成，並供應多家墨爾本知名咖啡館。Malvern 高街旗艦店是品牌對外展示精品咖啡文化的核心據點。

      為什麼值得專程來

      ☕ 這裡適合什麼人

      顧客回饋
