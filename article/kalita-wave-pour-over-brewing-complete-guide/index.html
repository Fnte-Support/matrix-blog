      Kalita Wave 沖煮完全指南：三孔平底濾杯的甜感秘密與 V60 差異解析

      咖啡知識 2026-06-19 By Daily Coffee

      Kalita Wave 是日本 Kalita 公司推出的平底三孔濾杯，憑藉波浪狀濾紙與慢流速設計，在手沖圈被暱稱為「甜感神器」。它的風味與 V60 截然不同——V60 強調明亮酸值與層次感，Kalita Wave 則偏向圓潤厚實的甜感口感。對於想嘗試第二個濾杯、追求不同風味軸的手沖玩家來說，Kalita Wave 是非常值得入手的進階選擇。本文從構造原理、與 V60 差異比較、濾紙特性、沖煮參數到注水手法，做完整攻略整理。

      Kalita Wave 是什麼？為何被稱為「甜感神器」

      Kalita Wave 的造型與 V60、Kalita 101 完全不同：它是一個金屬圓盤，底部平坦、上方略開闊，整個濾杯沒有把手。底部有「三個等距的小圓孔」負責排水，而非 V60 的一個大孔。這個構造看似簡單，卻直接影響了水流路徑與咖啡粉床的浸漬時間，進而決定最終杯中的風味走向。

      Kalita Wave 最迷人之處在於「容錯率高」與「甜感突出」。三孔設計讓水流速度比 V60 慢，咖啡粉在濾杯中會有更長的浸漬時間，萃取率容易落在 SCA 建議的 18-22% 黃金區間，產生厚實 body 與明顯的焦糖、堅果、巧克力甜感。即使注水節奏不夠精準的新手，Kalita Wave 也能給出相對穩定、不會過酸或過澀的結果，這也是它被咖啡廳廣泛採用的原因。

      Kalita Wave 主要有兩個尺寸：155（1-2 杯） 與 185（2-4 杯），材質有不鏽鋼、銅、塑膠三種。不鏽鋼 Kalita Wave Steel（俗稱「鋼款」）是台灣玩家最常入手的版本，散熱穩定、造型洗鍊；銅款是日本限量發售、保養費心但保溫性極佳；塑膠款價格最親民，適合剛入門的玩家。

      Kalita Wave 與 V60 的六大關鍵差異

      Kalita Wave 與 V60 是手沖圈最常被比較的兩款濾杯，但設計哲學其實完全相反：V60 是「快流速、高技法要求、強調酸值與層次」，Kalita Wave 是「慢流速、高容錯率、強調甜感與 body」。理解這六個差異，能幫助你判斷自己適合哪一款。

      差異一：底部結構——V60 是單一大孔，水流直接往下流；Kalita Wave 是三個小孔，水流從三個點均勻分散，咖啡粉床接觸時間更長。

      差異二：濾杯角度——V60 是 60 度錐形，咖啡粉呈薄層排列；Kalita Wave 是近乎平底，咖啡粉堆積成較厚的圓餅狀，萃取路徑長。

      差異三：流速——V60 流速約 4-5 ml/s，Kalita Wave 約 2-3 ml/s，沖煮時間自然拉長。

      差異四：風味軸——V60 偏明亮酸值、花果香；Kalita Wave 偏厚實甜感、堅果焦糖。

      差異五：容錯率——V60 對注水速度、繞圈節奏非常敏感；Kalita Wave 因為慢流速，注水節奏稍有偏移仍能維持穩定萃取。

      差異六：濾紙材質——V60 濾紙是錐形斜紋；Kalita Wave 濾紙是圓形波浪狀，與濾杯底部完全密合，這也是其名稱「Wave」的由來。

      Kalita Wave 濾紙特性：波浪狀的特殊設計

      Kalita Wave 的濾紙是整個系統的靈魂。不同於一般濾紙的平整圓形或錐形，Kalita Wave 濾紙在邊緣設計了 20 條均勻分布的「波浪摺痕」，剛好與濾杯內側的 20 條凸起肋條緊密貼合，帶來三個關鍵效果。

      第一，氣道效應。波浪摺痕讓熱水即使在注水中段也不會完全密封濾紙與濾杯，可讓空氣從肋條間隙排出，避免真空效應造成流速突然變慢或停止。

      第二，萃取均勻度。波浪狀讓濾紙內側平整貼在咖啡粉床上，沒有 V60 濾紙那種單點肋條接觸造成的「溝槽效應」，整體萃取更均勻。

      第三，流速穩定。因為氣道暢通，Kalita Wave 的流速從沖煮開始到結束都相對穩定，比較不會發生「前段快、後段慢」的不一致問題。

      濾紙材質方面，Kalita Wave 濾紙有「白色漂白」與「棕色未漂白」兩種。白色濾紙紙質較薄、流速稍快、雜味最少；棕色濾紙紙質較厚、流速稍慢、保留較多油脂，風味更厚實。多數玩家建議先從白色濾紙開始，習慣後再嘗試棕色。Kalita Wave 濾紙不能與其他濾杯混用——圓形波浪形狀是為專屬濾杯設計的，換到 V60 上會無法貼合。

      Kalita Wave 沖煮參數設定（粉水比、水溫、研磨）

      Kalita Wave 的沖煮參數設定邏輯與 V60 不同。因為流速慢、浸漬時間長，粉水比可以略低、研磨可以略粗、水溫可以略低，避免過萃。以下是經多次測試的建議起點：

      粉水比：1:15 為標準起點，1:14 適合喜歡厚實 body 的玩家，1:16 則偏向清爽。冰手沖的比例要再放寬到 1:11（熱沖段）加冰塊稀釋。

      水溫：淺焙豆建議 92-94°C，中焙 88-91°C，深焙 85-88°C。Kalita Wave 因為流速慢，高溫容易過萃；比 V60 建議溫度低 1-2°C 是常見的調整方向。

      研磨度：比 V60 略粗 0.5-1 格（用 Comandante C40 為例，V60 大約 22-25 格，Kalita Wave 建議 24-27 格）。太細會讓三個小孔排水不及產生積水；太粗則萃取不足、味道偏水。

      總沖煮時間：2-3 分鐘為宜。1:15 粉水比、20g 粉、注水 300g，建議在 2:30 左右完成注水，整個沖煮含滴濾結束約 3 分鐘。

      悶蒸時間：30-45 秒，使用粉量 2-3 倍的熱水（20g 粉用 40-60g 水）繞圈悶蒸。Kalita Wave 因為平底，悶蒸時整個粉床會均勻膨脹，視覺效果非常療癒。

      標準三段式注水教學：5 分鐘學會 Kalita Wave 沖煮

      Kalita Wave 適合「穩定節奏注水」，不需要 V60 那種極細的水流控制。以下是三段式注水流程：

      第一段：悶蒸（0:00 - 0:45）。從中心開始、繞小圈向外、再繞回中心，注水量為粉重的 2-3 倍。當粉床完全被熱水浸潤、表面呈現飽滿隆起時，停止注水並等待 30-45 秒。Kalita Wave 的悶蒸階段視覺效果特別好——整個粉床會像蛋糕一樣膨起來，這是二氧化碳正在排出的訊號。

      第二段：主注水（0:45 - 2:00）。分兩到三次注水至目標水量。每次注水時維持穩定的繞圈節奏，圈半徑約為粉床半徑的 2/3，不要直接沖到濾紙邊緣。每次注水之間留 10-15 秒讓水位下降，避免「積水」造成通道效應。Kalita Wave 對繞圈方向（左/右繞）不挑，但節奏要穩定。

      第三段：等待滴濾（2:00 - 3:00）。達到目標水量後停止注水，讓剩餘的水自然滴完。Kalita Wave 的滴濾階段通常需要 20-40 秒，讓咖啡粉與水的接觸達到最佳平衡點。如果滴濾時間太長（超過 1 分鐘），表示研磨可能太細，下次調粗 1 格再試。

      進階技巧：繞圈速度。建議每圈 3-4 秒，繞 5-6 圈注入 100g 水。繞太快（<2 秒/圈）會擾動粉床；繞太慢（>5 秒/圈）注水時間拖太長會過萃。

      Kalita Wave 常見風味問題與排除指南

      Kalita Wave 的高容錯率不代表不會出問題。以下是三個最常見的風味異常，附上成因與排除方法：

      問題一：喝起來偏水、沒什麼味道。原因通常是研磨太粗或水溫太低。Kalita Wave 三孔流速慢，研磨太粗會讓水「走短路」直接穿過粉床，萃取率不足。建議先把研磨調細 1-2 格；如果還是不行，確認水溫是否達到建議區間。另一個常見盲點是注水節奏太慢，熱水在濾杯中停留時間過長反而過度萃取，可以試著加快注水節奏。

      問題二：喝起來有澀感、尾韻卡喉。原因通常是研磨太細或水溫太高。Kalita Wave 流速慢，研磨太細會讓三個小孔排水不及，粉床積水產生過萃。建議把研磨調粗 1-2 格，並確認水溫沒超過 94°C。中深焙豆可以把水溫降到 86-88°C 試試。

      問題三：味道平淡、沒有層次。原因通常是粉水比偏高（1:16 以上）或注水過於均勻沒有分段。Kalita Wave 的風味層次來自於悶蒸、主注水、等待滴濾三段的節奏變化，如果全程都用同樣的注水速度，會把咖啡的層次感「沖」平。建議在第二段主注水中間留一段 10-15 秒的停頓讓粉床「靜置」。如果都試過，可以嘗試換用棕色未漂白濾紙強化甜感，或改用銅款 Kalita Wave 提升淺焙豆風味表現。

      Kalita Wave 155 與 185 怎麼選？容量對應建議

      Kalita Wave 主要有兩個尺寸，數字代表濾杯上緣直徑（單位 mm）。

      Kalita Wave 155：上緣直徑 155mm，建議粉量 15-25g（沖出 1-2 杯）。這是單人飲用或情侶共飲的甜蜜點，也是最多人入手的尺寸。平常都是 1 個人喝、或每次只沖 1 杯，建議直接選 155。

      Kalita Wave 185：上緣直徑 185mm，建議粉量 25-40g（沖出 2-4 杯）。適合家庭、辦公室、招待朋友。家裡有 2 個以上咖啡成員、或者想一次沖一壺冰手沖，185 是更實用的選擇。

      另外還有 100 與 200 兩個尺寸：Kalita Wave 100 是超小杯版本（建議粉量 10-15g），適合單人品飲精品豆；Kalita Wave 200 是商業咖啡廳用的大容量版本（粉量 40g 以上），一般家用不建議。

      材質方面，不鏽鋼是台灣玩家的主流選擇，散熱均勻、保養容易；銅是發燒友的玩具，售價較高（NT$3000+）、保養費心（會氧化需要定期擦拭），但保溫性極佳，淺焙豆的甜感表現明顯優於不鏽鋼；塑膠則是最平價的選擇，價格只要不鏽鋼的 1/3，缺點是塑膠感較重、散熱稍差，但對於剛入門、想先試試看 Kalita Wave 風味的玩家來說，是非常好的起點。建議：新手從 155 不鏽鋼開始，等熟悉沖煮特性、確定喜歡這個風味軸之後，再升級銅款或加買 185。

      Kalita Wave 一定要用專用濾紙嗎？可以用 V60 濾紙替代嗎？

      不可以。Kalita Wave 濾紙是圓形波浪狀、底部有三孔對應設計，與 V60 錐形斜紋濾紙完全不通用。強行把 V60 濾紙折成圓形塞進 Kalita Wave 會造成貼合不良、流速不穩定，風味也會失控。Kalita Wave 濾紙有「白色漂白」與「棕色未漂白」兩種可選，前者紙質較薄、流速快、雜味少；後者紙質較厚、保留較多油脂、甜感更厚實。多數玩家建議先從白色濾紙開始。

      Kalita Wave 沖煮時間要多久才正常？

      以 20g 粉、注水 300g（粉水比 1:15）為例，建議總沖煮時間 2:30 - 3:00 之間。時間太短（<2:00）通常是研磨太粗，萃取不足；時間太長（>3:30）通常是研磨太細或注水節奏太慢，過萃悶在粉床裡。3:00 - 3:30 之間風味通常還可接受，可以用「降低水溫 1-2°C」平衡；超過 3:30 還在滴濾，建議直接調粗 1 格研磨。

      Kalita Wave 跟 Kalita 101 有什麼差別？

      Kalita 101 是 1969 年推出的梯形三孔濾杯（底部窄、上方寬、有把手），Kalita Wave 是 2010 年推出的平底三孔濾杯（無把手）。兩者都是三孔設計，但 Kalita 101 偏中規中矩，風味介於 V60 與 Kalita Wave 之間；Kalita Wave 因為平底設計讓咖啡粉堆積更厚，浸漬時間更長，甜感更明顯。新手入手 Kalita 系列多數直接選 Kalita Wave，但 Kalita 101 仍有死忠支持者，特別是喜歡「V60 風味 + Kalita 穩定性」混合體驗的玩家。

      Kalita Wave 銅款真的值得多花兩三倍價格嗎？

      銅款 Kalita Wave 的價格大約是不鏽鋼款的 2-3 倍，差異主要在「保溫性」。銅的熱傳導係數比不鏽鋼高約 10 倍，能更穩定維持水溫不因環境散熱下降。對淺焙豆（建議水溫 92-94°C）來說這個差異非常明顯——銅款沖出來的淺焙豆甜感更突出、層次更豐富。中深焙豆（85-88°C）的差異較小，預算有限的玩家可先用不鏽鋼款，等確認喜歡 Kalita Wave 風味後再升級銅款。
