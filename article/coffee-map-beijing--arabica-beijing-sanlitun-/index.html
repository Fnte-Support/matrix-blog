      北京｜% Arabica, Beijing (Sanlitun) — 咖啡地圖

      咖啡地圖 2026-08-08 By Daily Coffee

      % Arabica, Beijing (Sanlitun)

      % Arabica 由日本人 Kenneth Shoji 於 2014 年在京都東山創立,品牌以極簡設計美學與精品咖啡哲學聞名,迅速成為亞洲最具辨識度的精品咖啡品牌之一。北京三里屯太古里旗艦店於 2017 年開幕,是 % Arabica 進軍中國市場的首店,落腳於北京最具國際氛圍的潮流地標三里屯。店內裝潢延續 % Arabica 一貫的極簡白色調與清水模風格,吧台後方設有烘豆機展示自家烘焙能力,主打來自夏威夷、巴拿馬、衣索比亞、肯亞等頂級產區的單品咖啡豆。% Arabica 對品質的堅持從選豆、烘焙到沖煮全程嚴格把關,使用自家品牌的烘焙曲線與專業吧台設備,在北京精品咖啡圈迅速建立口碑。

      為什麼值得專程來

      % Arabica 是亞洲最具辨識度的精品咖啡品牌之一,北京三里屯太古里旗艦店為品牌進軍中國的首店,以極簡設計美學與嚴格品質把關聞名,是北京精品咖啡愛好者朝聖地標,並為國際旅人熟悉的精品咖啡指標,品牌全球辨識度極高。

      ☕ 這裡適合什麼人

      對亞洲極簡設計風格精品咖啡店有興趣的探索者、追求國際精品咖啡品牌品質的咖啡愛好者、在三里屯商圈逛街想找個有質感精品咖啡空間歇腳的深度旅人,以及北京外籍人士社群與潮流文化工作者,以及國際精品咖啡品牌的忠實粉絲。

      推薦品項

      % Arabica 招牌 Single Origin（夏威夷 Kona 或巴拿馬藝伎）、Blend Latte（招牌拼配拿鐵）、Espresso Single Origin

      顧客回饋

      被《Time Out 北京》評選為「北京必訪精品咖啡店」之一,Google Maps 4.5 星(逾 600 則評論),被譽為「三里屯最具設計感的精品咖啡店」。媒體背書:Time Out 北京、That's Beijing、Brand 品牌官網 case study 收錄。
