前言：兩種濾杯，兩種萃取哲學

手沖咖啡的器具選擇，往往決定了咖啡風味的起點。Hario V60 與 Kalita Wave 是目前最受歡迎的兩款手沖濾杯，卻代表著完全不同的設計理念與沖煮哲學。

V60 以其錐形構造與螺旋溝槽，引導熱水沿著設計好的路徑流動，追求的是咖啡風味的層次感與清晰度。Kalita Wave 則以平底設計與專利波浪紋結構，實現更穩定均勻的萃取，帶來厚實平衡的咖啡口感。

理解這兩種設計的本質差異，不只是選購參考，更是深入手沖咖啡萃取原理的鑰匙。本文將從濾杯設計、萃取原理、風味表現到實際沖煮建議，進行全面且深入的分析比較。

濾杯設計的根本差異

兩款濾杯在物理結構上的差異，決定了它們截然不同的沖煮特性。

V60 錐形設計

Hario V60 的核心特點在於其 60 度錐角與螺旋溝槽。這種設計讓熱水沿著螺旋溝槽向下流動，注水位置直接決定了熱水的流動路徑。當你在 V60 中心注水時，水會向外擴散；當你在邊緣注水時，水則會沿溝槽快速流下。

V60 的底部只有一個大孔，孔徑可透過金屬蓮花座進行三段式調整。這種單孔設計賦予了沖煮者極大的控制權——你可以精細控制熱水流經的區域與時間，進而精準調控萃取過程。

Kalita Wave 平底設計

Kalita Wave 的平底三孔設計，確保咖啡粉床在萃取後呈現平坦均勻的狀態。三個小孔均勻分佈在底部，使熱水均勻通過整個粉層，避免了錐形濾杯中常見的中心與邊緣萃取不均問題。

傳統梯形濾杯的致命缺點是熱水容易沿著濾杯壁快速流下，造成所謂的「邊緣通道效應」（wall channelling）。Kalita 與 Vst 合作開發的專利波浪紋（Wave）設計，在濾杯壁與濾紙之間創造了一層薄薄的空氣通道，徹底改善了這個問題。

波浪紋設計讓 Kalita Wave 在保持平底萃取穩定性的同時，也具備了接近錐形濾杯的排水效率，被精品咖啡界譽為「平底版 V60」。

萃取原理與風味的差異

不同的物理結構，造就了兩款濾杯在萃取特性上的顯著差異。

V60 的萃取特性

V60 的錐形設計讓沖煮者可以透過改變注水位置來控制萃取範圍。中心注水時，熱水向外擴散，萃取範圍廣；邊緣注水時，水沿螺旋溝槽快速流下，萃取集中在特定區域。這種可控性讓 V60 能夠展現更豐富的層次感。

V60 萃取出來的咖啡通常具有以下特徵：

  • 明亮的酸質：清晰的層次感，酸香明顯
  • 透明的風味：能清楚品嚐到咖啡豆的產地特性與處理法特色
  • 較輕盈的Body：口感相對清爽，不那麼厚重
  • 依賴沖煮技術：同樣的配方，不同手法可能產生截然不同的風味

Kalita Wave 的萃取特性

平底設計讓咖啡粉在整個濾杯底部均勻分布，熱水均勻通過每一個區域，萃取的均勻度較高。這種穩定性讓 Kalita Wave 萃取出來的咖啡通常具有以下特徵：

  • 柔和的酸質：酸感圓潤，不那麼尖銳
  • 厚實的口感：Body 較飽滿，有重量感
  • 穩定的風味：同一配方，風味再現性高
  • 容錯性較高：沖煮手法的小瑕疵較不易被察覺

下水速度與萃取效率

V60 的單孔設計讓沖煮者可以透過控制孔徑或注水方式來調整下水速度。高流速適合快速萃取的淺焙豆，低流速則能為深焙豆提供更充分的萃取時間。

Kalita Wave 的三孔設計下水速度相對穩定，但若濾紙與濾杯貼合不良，仍可能出現排水不順的問題。波浪紋設計大幅改善了這個狀況，但在高粉量沖煮時仍需注意分段注水的節奏。

兩種濾杯的適用場景

選擇哪一款濾杯，取決於你的沖煮需求與使用場景。

V60 適合的使用者

如果你追求咖啡風味的層次感與變化，喜歡透過改變注水手法來探索不同的風味表現，V60 是更合適的選擇。V60 也能更忠實地呈現淺焙豆的產地特色，適合喜歡品嚐單品咖啡、重視產地風土的咖啡愛好者。

然而，V60 的缺點也很明顯：它對沖煮技術的要求較高，注水手法不當容易造成萃取不均勻。新手使用 V60 可能需要較長的學習曲線，才能稳定萃取出滿意的咖啡。

Kalita Wave 適合的使用者

如果你的首要目標是穩定的咖啡品質、而非追求風味的極致變化，Kalita Wave 的高再現性會是更大的優勢。它適合商業場所或早餐時段需要穩定出杯的情境，也適合不想花太多心思在沖煮技巧上的日常使用。

Kalita Wave 的容錯性較高，即使注水速度稍有變化，也不會對最終咖啡品質造成太大的影響。這種「友善」的設計讓它成為許多咖啡館的標準配備。

沖煮配方建議

以下是兩款濾杯的參考沖煮配方。請記住，這只是起點——你的研磨機、水質與咖啡豆特性都會影響最終的萃取參數。

V60 沖煮配方參考

使用 15 克咖啡粉，研磨刻度約在中等偏細（視研磨機而定），水溫 92-93°C，粉水比 1:15，總注水量 225 克。注水方式為一段式或多段式，視咖啡豆特性而定。總萃取時間目標為 2 分 30 秒至 3 分鐘。

第一段注入 30-45 克水進行預浸，等待 30-45 秒讓咖啡粉充分排氣。第二段以小水流緩慢注水，維持咖啡粉床的穩定浸潤。第三段視情況加入，確保達到目標總注水量。

Kalita Wave 沖煮配方參考

使用 15-18 克咖啡粉，研磨刻度中等（比 V60 略粗），水溫 92-93°C，粉水比 1:15 至 1:16，總注水量 225-288 克。

Kalita Wave 的注水方式建議以「淹沒式」（immersion）為主，初期讓熱水覆蓋整個咖啡粉床，之後以穩定的小水流持續注水。由於平底結構的萃取效率較高，可以將總萃取時間縮短至 2 分至 2 分 30 秒。

實際沖煮的注意事項

無論選擇哪一款濾杯，以下幾點都是確保穩定萃取的關鍵：

研磨的新鲜度：這是影響萃取最大的單一因素。咖啡粉研磨後表面積大幅增加，香氣化合物開始快速氧化，建議在研磨後 15-30 分鐘內使用完畢。

研磨機的影響：錐刀（burr）與平刀（flat burr）研磨機即使設定相同的刻度，產生的顆粒形狀與萃取特性也會有所不同。了解你的研磨機特性，才能更好地調整其他參數。

濾杯的預熱：在沖煮前用熱水充分預熱濾杯與下壺，可以減少萃取時的溫度損失，確保萃取溫度的穩定性。

結論：沒有最好，只有最適合

V60 與 Kalita Wave 代表的是兩種不同的手沖哲學，而非絕對的優劣之分。V60 給予沖煮者極大的控制空間，適合願意投入時間學習沖煮技術、享受探索風味變化的咖啡愛好者。Kalita Wave 的穩定再現性，則更適合追求方便性與穩定品質的日常沖煮場景。

理想的做法是兩款濾杯都擁有，根據當下的心情與需求選擇合適的工具。交替使用不同濾杯沖煮同一款咖啡，是深入理解兩種設計差異的最佳方式。

常見問題

V60 和 Kalita Wave，哪個更適合新手？

Kalita Wave 對新手更友善，因為它的平底設計提供了較高的容錯率。V60 的萃取效果高度依賴沖煮者的注水技術，新手可能需要較長的時間才能掌握均勻萃取的要領。

兩款濾杯做出來的咖啡，風味差異大嗎？

在同一款豆子、相同參數下，V60 通常萃取出酸質更明亮、風味更清晰的咖啡；Kalita Wave 則呈現較厚實的口感與較柔和的酸質。這個差異在淺焙豆上特別明顯。

可以用 V60 的參數直接沖 Kalita Wave 嗎？

不建議。Kalita Wave 的萃取效率較高，通常需要將研磨調粗半格左右，以避免萃取過度。注水方式也略有不同，Kalita Wave 更適合穩定的中水流，而非 V60 常用的分段脈衝式注水。

除了 V60 和 Kalita Wave，還有哪些值得一試的濾杯？

蛋糕型濾杯（Melitta style）是另一個受歡迎的平底設計流派。Chemex 以其優雅的設計與厚實的咖啡口感著稱。Origami 結合了錐形與平底的優點，是近年來備受關注的新興設計。

我應該兩款都買嗎？

如果你對手沖咖啡有認真的興趣，建議兩款都入手。交替使用可以幫助你更清楚地感受到不同設計帶來的風味差異，也是提升沖煮技術的有效練習方式。
